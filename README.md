## 👋 About Me

I am a **Manual Quality Analyst** passionate about delivering reliable, user-friendly, and high-quality software products.

I specialize in **manual software testing, functional testing, regression testing, UI/UX validation, web application testing, mobile application testing, API testing, exploratory testing, and defect management**.

My approach to Quality Assurance is focused on understanding the product from both the **business perspective and the end-user perspective**.

I don't only verify whether a feature works. I also look for:

- Edge cases
- Unexpected user behavior
- Validation issues
- UI inconsistencies
- Navigation problems
- Data issues
- Compatibility issues
- Usability problems
- Regression defects
- Integration issues

### 🎯 My QA Philosophy

> **Quality is not just about finding bugs. Quality is about preventing problems, improving experiences, and delivering confidence.**

### 📝 Bug Report Structure

**Bug Title**

**Environment**

**Module**

**Preconditions**

**Actual Result**

**Priority**
